# Sappy Seals art theme

New immutable art ID `sappy-seals-art`; the retired `sappy-seals` colour ID continues to migrate to Mint & Money. Fixed Flat black surfaces and white accents; restrained rounded buttons, dashed dialog/picker outlines, smooth original Magic Money/Swap logos. Reference: https://www.sappy.lol/signin and https://www.sappy.lol/seals.

The original user-provided Live2D seal from `C:/Users/balla/Documents/seal` is bundled unchanged. The supplied `Seal Login.4096/texture.png` is the default; `texture_00.png` remains a locally persisted alternate, selected with the 28px shirt icon immediately beside refresh on the active theme card. `SappySeal.tsx` renders it centred immediately above Networks/Tokens/Collectibles, with paws behind the tab fence. Its final model fit is 26% smaller than the first enlarged preview; portfolio heading uses16px top/4px bottom padding and zero extra margin; the seal/tabs/search block is lifted32px independently, keeping heading/tool positions and adding list space and reserved seal height reduced to 90px. Browser-local pointer/touch coordinates drive Cubism focus; idle animation stays local. The Windows mouse bridge and websocket helper are not included. No wallet APIs or addresses enter the animation runtime.

Ownership is a read-only Ethereum mainnet ERC721 check against `0x364C828eE171616a39897688A831c2499aD972ec`: chain ID, fixed block, interface support and positive balance. Existing current-account generation guards, 90-second freshness, refresh, timeout and fail-closed behavior remain shared with other collection themes. No NFT signatures, transactions or persistent entitlement.

Core, Pixi 5.3.12 and pixi-live2d-display are lazily loaded only after the theme is selected. Model rendering is capped at 30fps / DPR1.5, paused for hidden/offscreen scenes and reduced motion, and destroyed on theme removal. Static head fallback covers WebGL/runtime failure. Third-party headers are retained. Official Pixi static uniform synchronizer is bundled via `resources/themes/sappy-seals/csp-install.ts`; its MIT license is included. Source: https://github.com/pixijs/pixijs/tree/v5.3.12/packages/unsafe-eval. The extension CSP is unchanged; no JavaScript unsafe-eval permission. To rebuild the patch: `npx esbuild resources/themes/sappy-seals/csp-install.ts --bundle --format=iife --outfile=src/renderer/assets/themes/sappy-seals/pixi-csp.js`.

Shared renderer implementation includes Electron, extension, Android and iOS builds, plus the matching palette in wallet browser chrome. Native-device animation and phone installation require separate verification. This task does not add a standalone ChainLens website theme.
