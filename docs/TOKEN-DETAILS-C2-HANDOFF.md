# C2: reviewed QR send integration and universal panel mappings

2026-10-14. C2 implementation complete; final full-gate result recorded below and in HANDOFF_LOG.md.

## Changes

- `src/renderer/components/SendModal.tsx` now calls `parseTokenQr` instead of stripping schemes/parameters from arbitrary scanned text. It accepts validated address-only input, shows errors/status, preserves amount/source/token identity, and never submits automatically.
- Camera cancellation leaves the existing recipient unchanged. Missing/throwing scanner has a paste fallback. Malformed addresses and payment URIs preserve the existing recipient and show a reason.
- A scan request is bound to the current public account/mode/chain/source/asset context and a request version. Results after manual recipient edits, dismissal, a newer scan, account switching or mode changes are discarded. Fee estimation/review are disabled during a pending scan.
- `DashboardPage.tsx` supplies `contextKey` to both native and token/NFT SendModal instances. It includes public account address/index, AGW address/ownership, account-switching state and testnet/privacy mode. Prepared forms close when this changes; an already broadcasting transaction retains its progress and result screen.
- Address validation failure no longer silently treats a pasted recipient as valid. The form explains validation failure and withholds fee estimation/review until validation succeeds.
- `e2e/token-details.spec.ts` now includes QR review/no-auto-send, request rejection/cancellation, late scan/manual edit/new form, and pending receive/account-switch journeys. Receive Copy is asserted against displayed address.

## Mapping review

- TokenDetailsPanel hands the latest WalletToken to the original `openTokenSend`; exact `rawBalance`/asset decimals are retained. Display balance is not transaction arithmetic.
- Ordinary receive comes from the account's network address; AGW receive comes from an owned Abstract mainnet smart account. No contract/mint/policy identifier is a recipient.
- Send remains source-correct via existing wallet handlers. AGW swaps remain unavailable. Special read-only assets keep details but no guessed receiving/signing path.
- Selection is account/mode/source-aware and case-preserving. Async receive results are guarded by key and effect cancellation. A real extension test verifies an account switch closes a pending Receive view and discards its late validation result.
- Network activity is explicitly unfiltered; no token-specific history claim is made. Unknown price is shown as unavailable. Programmable execution and USDCx outbound remain disabled/unwired.
